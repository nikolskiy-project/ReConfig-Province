О программе

Настрой Province один раз.
Переключайся когда угодно.

ReConfig Province избавляет от ручного поиска, копирования и замены конфигураций игры. Всё нужное хранится в одном месте и применяется за пару действий.

01

Конфиги под рукой

Добавляй несколько вариантов coreconfig.xml, назначай им имена и иконки и мгновенно переключай активный.

02

Готовые бинды

Применяй предустановки биндов с нужными параметрами персонажа без ручного редактирования десятков строк.

03

Обновляется само

Приложение получает новые версии из GitHub Releases, показывает изменения и умеет обновляться с перезапуском.

FAQ

Коротко о главном

Нужна ли установка?

Нет. ReConfig Province распространяется как самостоятельный Windows EXE. Запускаешь файл и работаешь.

Где хранятся мои конфиги?

Пользовательские настройки и конфиги хранятся отдельно в папке данных пользователя Windows, поэтому обновление приложения их не удаляет.

Откуда сайт берёт версии?

Сайт обращается напрямую к GitHub Releases этого репозитория и автоматически строит список опубликованных версий и ссылки на EXE.
