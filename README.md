# ReConfig Province

**ReConfig Province** — современный менеджер конфигураций и биндов для MTA Province.

Приложение позволяет удобно хранить, редактировать и переключать различные конфигурации `coreconfig.xml`, использовать готовые предустановки биндов и управлять настройками игры через современный графический интерфейс.

## ✨ Возможности

- Быстрое переключение между сохранёнными конфигами
- Импорт и экспорт `coreconfig.xml`
- Встроенный редактор конфигураций
- Создание собственных пресетов
- Выбор названия и иконки для каждого конфига
- Автоматическое применение готовых наборов биндов
- Замена конфликтующих назначений клавиш
- Сброс установленных биндов
- Автоматическое определение папки MTA Province
- Настройка акцентного цвета интерфейса
- Современный тёмный интерфейс с плавными анимациями
- Автоматическая проверка обновлений
- Загрузка и установка новых версий прямо из приложения

## 🖥️ Интерфейс

ReConfig Province создан с упором на удобство и современный внешний вид.

Программа включает:

- плавные переходы и анимации;
- настраиваемый цвет интерфейса;
- собственные выпадающие списки и элементы управления;
- удобное управление сохранёнными конфигурациями;
- встроенную систему обновлений.

## 🚋 Для чего нужна программа?

При использовании MTA Province настройки и бинды хранятся в файле `coreconfig.xml`.

ReConfig Province избавляет от необходимости вручную искать, копировать и заменять этот файл.

Достаточно сохранить необходимые конфигурации в программе и переключаться между ними в несколько нажатий.

## 🔄 Обновления

ReConfig Province автоматически проверяет наличие новой версии.

Если обновление доступно, приложение:

1. показывает номер новой версии;
2. отображает список изменений;
3. загружает обновление;
4. проверяет целостность файла;
5. устанавливает новую версию;
6. автоматически перезапускается.

## 📁 Пользовательские данные

Настройки и сохранённые конфигурации хранятся отдельно от самой программы в папке пользователя Windows.

Это позволяет обновлять или перемещать приложение без потери сохранённых пресетов.
